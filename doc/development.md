# 开发与验证

[返回 README](../README.md)

## 运行测试

在项目根目录执行：

```bash
python -m unittest discover -s tests -v
```

测试动态构造合成字体，不需要提供真实字体文件。覆盖不同名称、字数、字符集合、
坐标尺度与预览数量，以及二进制往返、预览同步、分段连接保护、笔端长短、
整字/局部缩放公式、叠加次序、随机复现、参数校验及不覆盖已有输出。
还覆盖加密元数据、不同格式版本、扩展字形字段、改名与损坏文件拒绝。
预览测试还检查采样加密不会被误认为几何位移、路径内部变形能被检测，以及叠加图共用坐标。

## 使用自己的字体做集成测试

在项目根目录显式传入需要测试的字体，以及一个尚不存在的输出目录：

```bash
python -m tests.validate_fonts "font-a.gfont" "font-b.gfont" --output "output/validation" --workers 2
```

脚本对每个完整字库执行只缩短、只延长、整字缩放、局部缩放、叠加变形、倍数为 1 六种测试。
非恒等模式默认各导出两套字体，并重复生成一次叠加结果以检查随机种子复现。
检查内容包括源文件哈希不变、完整字符集合、落笔段数、非名称元数据、附加字形字段、
内置预览一致性、输出哈希、长短变化方向和不同变体的实际轨迹差异。

打开输出目录中的 `index.html` 可浏览各字体的实际导出对比图；`report.json` 保存全部测试结果。
每种模式的 `preview.html` 支持原字叠加、放大和交替显示，图形使用导出后读回的 float32 坐标。
每个字体目录还包含独立报告和生成结果。任何字体未通过时命令返回非零退出码。
这项测试需要用户提供字体，不属于默认单元测试，也不会自动扫描或上传字体。

### 如何理解差异指标

`changed_glyphs` 统计序列化字形记录不同的数量；仅增加采样点也可能计入，不能用于证明视觉差异。
`manifest.json` 的 `preview_differences` 按变体顺序保存预览字符的以下指标：

- `same_coordinates`：轨迹点是否完全一致。
- `max_sampled_displacement`：每条 path 按自身弧长比例取 33 个对应位置，比较得到的最大位移，单位为字体坐标。
- `max_sampled_displacement_percent`：上述位移除以原字边界框的最大边长，再乘以 100；原字没有尺寸时为 `null`。
- `path_length_ratios`：按原始 path 顺序记录实际长度比；原路径长度为零时为 `null`。

抽样位移不是严格的几何最大值，也不是可见性评分；细小局部变化可能落在采样位置之间。
比较前后字形时，每行所有列共用坐标范围和显示比例，避免分别归一化掩盖变化。
旧默认 ±5% 的局部缩放在小图中可能小于线宽，应结合放大、交替对比和参数范围判断效果。
当前采用预实验 B 方案：长短 ±15%、局部缩放 ±25%。

## 单字参数预实验

调整默认幅度前，可以先用用户字体中的一个字做参数扫描：

```bash
python -m tests.parameter_sweep "font.gfont" --char "木" --seed 42 --count 6 --output "output/parameter-sweep"
```

浏览器打开输出目录中的 `index.html`，分别调节长短和局部缩放。
两项各有 0、±5%、±10%、±15%、±20%、±25%、±30%、±40% 八档，0 为恒等对照。
每组生成六个配对样本；相同样本在不同幅度下复用相同随机序列。
局部缩放半径固定为 0.35，中心采用随机点；叠加时中心相对于长短调整后的字框确定。
所有格子共用坐标与比例，支持纯字形、原字叠加、交替显示及不同显示尺寸。

三张独立 SVG 保存长短、局部缩放、相同幅度叠加的完整矩阵，`report.json` 保存参数、源哈希和全部字形坐标。
图形通过当前变形算法生成，并按 `.gfont` 字形记录编码后读回；此实验不导出整套字体，也不修改默认参数。
单字实验用于筛选候选参数，不能证明全字库的自然程度或实机效果。

## 代码结构与格式扩展

```text
glymorph/
  cli.py          命令行入口
  pipeline.py     公共文件处理流程 / Python 接口
  font.py         已支持格式的读写
  metadata.py     加密元数据的格式封装
  transforms.py   可选变形与参数
  geometry.py     路径几何计算
  preview.py      根据输入字符集合生成预览
tests/            不依赖真实字体的测试
```

字体文件、生成结果以及本地调研材料不纳入 Git，也不是安装或运行的依赖。
格式扩展应放在读写层，变形层只操作通用的字形与轨迹数据。
当前解析器支持已经验证的 `.gfont` 格式布局，并不覆盖所有同扩展名文件。
已支持明文和加密元数据，以及字符名和十进制码点名的 ZIP 条目。
详细布局、保留字段和参考资料见 [.gfont 格式说明](gfont-format.md)。

## 重新生成效果示意图

README 中的效果图使用仓库内手工构造的示意轨迹，直接调用当前变形算法，
不依赖用户字体。长短图使用固定种子和非零抽样范围，展示同一字中各条 path 的独立变化；
标注的倍率由变形前后的实际路径长度计算，不能用全字共用的固定倍数代替这一示例。
若修改算法，可在项目根目录重新生成 SVG：

```bash
python -m docs.generate_examples
```

示意图生成脚本见 [generate_examples.py](../docs/generate_examples.py)，
图片保存在 [docs/images/](../docs/images/)。
它们用于说明变形效果，不是字体导出或实机书写的验证结果。
